# 📝 Task Master App

## About

A modern full-stack **task management** (todo) application built with a focus on speed, scalability, and great user experience.

Users can **create**, **update**, **delete**, and **manage** their tasks easily, while enjoying a smooth and fast interface.

---

## Features

- User Authentication (JWT-based)
- Create, update, delete tasks
- Organize tasks with filters and categories
- Responsive, accessible UI
- Real-time updates using React Query
- Secure backend with JWT authentication and hashed passwords

---

## 🧰 Tech Stack

### Frontend

- React 18
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Router
- Zod (validation)
- Axios (HTTP client)
- Lucide React (icons)
- React Hook Form

### Backend

- Node.js
- Express.js
- MongoDB + Mongoose
- bcryptjs (password hashing)
- jsonwebtoken (JWT auth)
- dotenv (env config)
- nodemon (dev auto-reload)
